# 播放器与视频进度条 · 4.5

沿用项目的 Lucide 线性图标和 `#84E36C` 选中色。本版右侧固定为五项：**音量按钮、音量条、截图、分辨率、播放速度**。可编辑 SVG、独立图标对应表、深色预览和设计变量一起交付；媒体播放与 Adobe CEP 宿主接入由前端实现。

## 文件入口

- `components/`：默认、播放中、悬停及轨道两端悬停、拖动、静音、循环、禁用、结束、加载、错误、紧凑布局，以及 360 / 392 / 480 / 568 / 736 px 宽度示例。
- `components/resolution-open.svg`、`components/speed-open.svg`：分辨率与倍速展开状态；对应独立浮层为 `resolution-popover.svg`、`speed-popover.svg`。
- `components/screenshot.svg`：截图操作的瞬时反馈。
- `previews/default.svg` / `.png`、`compact.svg` / `.png`、`overview.svg` / `.png`：默认、窄面板与完整状态预览。
- `previews/right-controls.svg` / `.png`：右侧五项控制设计。
- `previews/icons-and-states.svg` / `.png`：图标与按钮状态。
- `icon-manifest.json`：图标文件、位置、尺寸和交互语义。
- `design-tokens.json`：颜色、尺寸、时间码、响应式与状态规则。

SVG 是交付源文件，PNG 用于核对效果。独立图标统一 `viewBox="0 0 24 24"`、`stroke-width="1.75"`、圆形端点和转角，使用 `currentColor`，没有远程资源依赖。需由宿主 CSS 控制颜色时，将 SVG 内联到 DOM；普通 `<img>` 不会继承页面的 `currentColor`。

## 布局与辨识

时间码位于顶部，进度轨道占据整行。轨道常态 3 px，悬停或拖动 5 px，透明命中区域高 24 px；滑块直径为 8 / 10 / 12 px。已播放为绿色，缓冲区为中灰，剩余轨道为深灰。

左侧依次为“上一项、播放/暂停、下一项、循环当前素材”。右侧保持“音量按钮、音量条、截图、分辨率、播放速度”的顺序，并始终右对齐。截图使用相机图标；分辨率显示 `AUTO` 或当前值（如 `1080p`）及下拉箭头；倍速显示 `1×` 等当前值及下拉箭头。普通右侧控件无常驻独立底框，悬停或展开时才显示轻微底色。

宽布局为 1024 × 132 px；568 / 736 px 保持同一行控制。宽度不超过 560 px 时，左侧播放控制和右侧辅助控制分成两行，面板增高至 176 px。360 / 392 / 480 px 均保留全部五项右侧控制及常驻音量条。当前与总时间码在 360 px 仍可同排显示。

## 按钮状态

| 状态 | 视觉与行为 |
| --- | --- |
| 默认 | 中性灰白图标，普通按钮透明背景。 |
| 悬停 | 图标提高亮度，轻微深色底，显示操作名称。 |
| 选中 | 生效的循环、静音等开关使用绿色；分辨率和倍速菜单用勾选标识当前选项。 |
| 禁用 | 降低透明度，保留位置，不响应点击或键盘激活。 |
| 按下 | 短暂加深按钮底色，释放后恢复；截图不保持选中。 |

播放时显示“暂停”图标，表示下一步可执行暂停。键盘聚焦使用独立轮廓；可读名称、图标和勾选标识共同传达状态。图标按钮须有可读名称；切换按钮同步 `aria-pressed`，菜单触发按钮同步 `aria-expanded`。分辨率与倍速虽然只显示简短数值，仍须分别提供 `title` 和 `aria-label`：“分辨率”“播放速度”。

## 进度与时间码

- 单击轨道跳到对应位置；仅悬停时显示候选时间码，当前播放位置不变。
- 浮动时间码贴近指针，靠近两端时向内收敛，保持在面板范围内。
- 拖动时显示候选位置；释放后提交，并恢复拖动前的播放/暂停状态。Escape 取消并还原拖动前位置。
- 所有跳转限制在 `[0, duration]`；轨道两端分别可达起点和终点。
- 使用等宽数字。已知帧率显示 `HH:MM:SS:FF`；未知帧率显示秒级时间，不推测帧率或擅自换算 drop-frame。
- 样例为 25 fps：当前 308 帧，对应 `00:00:12:08`；总长 1725 帧，对应 `00:01:09:00`。这些数字仅为设计示例。

建议采用原生范围控件承接键盘交互：已知帧率时左右方向键移动一帧；未知帧率时使用宿主明确的秒级步长；Home / End 到起点 / 终点。这是进度控件的键盘行为，不新增逐帧按钮或菜单。可选 Page / Shift 组合快捷键可移动 5 秒，由宿主明确绑定。空格只在播放器拥有焦点且用户未输入文字时切换播放，避免占用 CEP 全局快捷键。

## 五项右侧控制

| 控制 / 标识 | 交互约定 |
| --- | --- |
| 音量 / `volume` | 音量为 0 时显示静音；取消静音恢复上一次非零音量。 |
| 音量条 / `volume-range` | 范围 0–1，宽窄布局均常驻；无音轨时禁用音量按钮与条，并保留原位置。 |
| 截图 / `camera` | 捕获当前已解码的视频帧；优先使用完整源帧。按下为瞬时状态，完成后显示提示。 |
| 分辨率 / `resolution` | 下拉切换预览分辨率，当前选项带勾选；闭合时显示 `AUTO` 或当前值。 |
| 播放速度 / `speed` | 提供 0.5×、0.75×、1×、1.25×、1.5×、2×；当前值带勾选，切换保留播放位置。 |

截图不截取整个桌面，不主动跳转进度；除宿主确有要求外，也不暂停播放。无有效视频帧或禁用状态下不可截图。截图默认优先采用完整源帧，不随预览分辨率降低而自动降级；无法获取时给出失败反馈。保存路径和文件格式由宿主回调决定。本设计不预设保存目录或格式。

分辨率示例选项为 `AUTO / 原始 / 1080p / 720p / 540p`，实际选项由宿主支持的预览流尺寸生成。`AUTO` 明确表示自动选择预览分辨率。原素材低于指定分辨率或宿主不支持时，相关项禁用或不显示；不承诺放大画质。切换只影响预览分辨率，保留播放位置、播放/暂停状态、循环、音量和倍速。切换期间可以显示忙碌状态，成功提交后更新显示值。

分辨率与倍速浮层通过 Escape 或外部点击关闭，关闭后恢复触发按钮焦点；同一时刻只打开一个浮层。

## 播放状态与交付边界

上一项/下一项切换素材，到边界禁用相应按钮。循环只针对当前素材。播放结束后点击播放从 0 开始；开启循环则回到起点继续播放。缓冲时在能力允许的情况下保留暂停操作。错误状态显示说明与重试；重试属于状态恢复操作。未就绪时保留布局且不显示虚构进度。

本交付包含离线 SVG 设计资源及规范，不包含媒体引擎；Adobe CEP 宿主中的显示、截图回调、预览分辨率和媒体交互需在接入后验收。
