# SVG 交付与交互规范 / 4.3.0

目标：Adobe CEP。图标统一 viewBox 0 0 24 24、描边1.75、圆端点；图标不含文字、字体、背景、脚本、外部CSS或远程引用。

核心 icons 由 currentColor 着色。states 是可独立预览的固定颜色版本，内部仍使用 currentColor；业务动态换色优先使用 icons，并在内联 SVG 上设置 color。尺寸变体位于 sizes/16、20、24，viewBox 不变。

默认工具栏图标20px，按钮32px、圆角5px，图标间距6px、组间距12px；菜单18px；缩略图操作18px、透明点击区域32px。时间码为纯文字，不使用时长图标。组件源图尺寸与图标画布是两类概念，components 不强制24画布。

## 工具栏布局

工具栏参考宽736px，总高134px，按宿主宽度伸缩。顶部工具区高40px，不显示左上角产品名称；右上保留“素材位置”按钮，使用文件夹图标与下拉箭头。浏览行位于y40至94，高54px；分类行位于y94至134，高40px。主浏览行背景#181f1a，工具栏表面#111713，分隔线#303b33；工具栏不使用包围整个区域的大圆角框。

浏览行从左到右为：常驻搜索框、仅看收藏、排序字段与方向、筛选与条件计数、弹性空白、卡片/列表/纯净视图组、缩放入口。搜索框参考位置x16，宽220px、高34px、13px文字，背景#101612、边框#3a493e。三种视图互斥，使用aria-pressed或等效单选语义；选中图标为#84e36c，底色#233722。缩放按钮打开包含原生range的浮层，范围150至260、步长10、默认190；列表模式禁用缩放但保留原位置。

## 公共界面状态

- 默认：中性灰图标、透明按钮背景。
- 悬停：更明亮的图标、浅灰绿背景。
- 选中：工具栏为绿色图标与低饱和绿色背景。缩略图的可见性及无底框操作规则见下节；本节工具栏状态不受缩略图调整影响。
- 按下：pointer/key-down 期间使用 pressedBackground 与 pressed；松开后恢复悬停或选中，不用按下表示持久选中。
- 禁用：主界面disabled颜色乘以0.38透明度；缩略图使用其独立disabledIcon颜色。原生button必须设置disabled，阻止鼠标与键盘业务事件。禁用优先于其他状态；已选中+禁用保留实心图形以保留状态语义。
- 聚焦：2px外框，3px间距；不得通过颜色单独表示键盘焦点。

## 缩略图与左对齐排版

图钉绕24画布的12,12中心顺时针旋转30度，已烘焙入SVG几何，不重复设置CSS旋转。未置顶时隐藏图钉及全部暗描边，包括默认 / 悬停 / 按下 / 禁用，不保留不可见的键盘焦点目标。置顶入口位于卡片右键菜单；公共原始pin.svg仍可用于该菜单。置顶后才在左上显示绿色实心图钉，点击取消置顶；选中+悬停 / 按下 / 禁用均保留实心形状。可见操作的32px点击区域保持透明，所有交互状态均不显示方形背景或边框；键盘焦点以贴合图形的可见描边反馈。收藏未选始终显示描边星标，已选为绿色实心。普通收藏不透明度86%，悬停100%，禁用45%；按下时缩小至94%，已选中按下变为同色相略深的绿色，松开后恢复原状态。收藏、置顶、卡片勾选是独立状态。

收藏和置顶无底板，前景由细暗描边保护可读性。图标暗描边3.1个画布单位、64%不透明度；文字暗描边1.5px、82%不透明度，仅沿字形边缘出现。时间码和格式为92%不透明的静态纯文字，不接收焦点或点击；仅这两个标签使用 #0c110e、fill-opacity 0.28、无边框、3px圆角的紧贴文字底框。文字左右内边距4px、上下2px，底框宽度=实际渲染文字宽度+8px。常规为12px字、14px行高、18px框高；紧凑为11px字、13px行高、17px框高。底框外边缘距图片左 / 右 / 下边缘4px。时间码靠左、格式靠右并统一基线，格式始终大写，不显示clock-3或film/image/image-play。16/20/24公共单图标尺寸变体和五种状态继续保留。

卡片页脚文件名和元数据均左对齐到实际缩略图左边缘，坐标为卡片左侧+2px，SVG使用text-anchor="start"。右侧勾选按钮保持原位置，文字可用宽度须预留勾选按钮、右边距与文字间隔。文件名和元数据各占一行，超长时省略并保留完整值供提示及辅助技术读取。160px窄卡片完整保留HH:MM:SS:FF与WEBM，两个底框仍在同一行。

图片边距2px，页脚高40px，卡片常态无底板；只有当前选中素材保留1px、80%不透明度的绿色外轮廓。精确几何和颜色见thumbnail/design-tokens.json，全部状态源图见thumbnail/components/，新设计重点效果见thumbnail/preview-dark.svg和同名PNG。

## 中文分类与数量

全部/视频/图片/音频/LUT采用13px、500字重、20px行高、0字距；当前分类使用绿色文字和2px下划线，五项互斥。工具栏按已过滤结果更新数量，数字使用等宽数字，单位“项”保持独立间距。数量只作统计文本，不充当选项菜单或素材位置入口。

未选择素材时，分类行右侧显示结果数量与复选框；存在选择时，原位置显示选中数量、打包、清除选择与复选框，左侧分类保持可用。复选框区分未选、全选、部分选择，按当前结果执行选择操作。打包仅处理当前选择，完成后不自动清空选择；清除选择只清除选择集合，不改变搜索、分类或筛选。

## 弹出与关闭

搜索框常驻，输入后实时更新查询和数量；有查询时显示清空按钮，清空后查询归零。搜索本身不打开浮层。旧文件名components/search-popover.svg与search-popover-filled.svg已改为搜索框兼容源图；规范入口是toolbar/components/search-field.svg与search-field-filled.svg。

筛选打开248px浮层，触发按钮显示生效条件数量，浮层内提供明确的清除筛选操作。排序入口同时呈现当前字段（参考稿为“时间”）与升降序方向。Esc关闭浮层并把焦点返回触发按钮，点击外部关闭；菜单打开时同组其他菜单关闭。菜单支持上下方向键、Home/End、Enter以及Esc。

素材位置按钮使用folder.svg（官方folder-cog形状），打开右上素材位置菜单，菜单包含“设置素材位置”“新建文件夹”“上传文件夹”。设置素材位置打开既有路径设置对话框，包含素材文件夹、选择文件夹、包含子文件夹、取消/保存；对应菜单或对话框打开时触发按钮呈打开状态。路径选择和文件系统读写由CEP宿主接口完成，不能把浏览器目录输入返回的名称当真实绝对路径。

新建文件夹和上传文件夹统一从素材位置菜单进入，不放在结果数量旁。新建名称不能为空，也不能包含路径分隔符；创建/上传通过宿主回调完成。提交时禁用重复操作，失败显示可读错误且保留输入。

## 响应式与字体

700px及以下浏览行按控件组换行，搜索框可独占一行，工具栏高度随内容增长；素材位置保持靠右。下排分类与数量/多选区域可分为两行。分类允许内部横向滚动，禁止页面横向溢出；视图组保持完整，禁用缩放不使其他控件移位。弹层宽度不超过视口减32px；路径输入可伸缩。系统字体使用PingFang SC / Microsoft YaHei / sans-serif，无字体下载。SVG源图里的中文为可编辑文本，图标本身不依赖字体。

## CEP 集成

建议把SVG内联到DOM后设置color。img标签的SVG不会继承父容器color；需要img时使用states固定色版本。不要依赖CSS字体图标。独立图标和组件SVG都可离线读取；组件预览中的素材图以data URI内嵌。组件SVG是设计源图，输入、菜单、checkbox、range需要前端使用原生DOM实现，不能把整张SVG截图当可用控件。

CEP包含的Chromium版本由宿主版本决定。本包主交付不要求React、container query、:has或原生dialog；附带浏览器预览若使用新特性，只是演示，宿主工程应按实际CEP版本适配焦点、弹窗和路径接口。

尚未在Adobe CEP宿主内实际集成测试。图标和组件源SVG为离线交付资源，PNG仅用于效果核对，仍需前端在目标宿主验证缩放、焦点、禁用与文件接口。
