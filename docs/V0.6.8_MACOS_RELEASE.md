# 0.6.8 Mac 内置媒体组件交付

2026-09-07。主机 macOS 26.5.1 / Apple Silicon。

## 本版行为

- 已有兼容的 FFmpeg / FFprobe：同目录配对，检测成功后复用，不覆盖或修改系统工具。
- 系统没有、版本太旧、缺少编码器或测试失败：自动使用包内的原生 Mac 架构工具。
- 内置工具损坏或无法运行：不执行损坏文件，不覆盖旧扩展；提示重新下载或查看随包修复说明。
- 安装器先把新扩展复制到自己的暂存目录，再使用与运行时相同的 resolver 检测；失败不替换旧安装。
- 插件检测异步执行并合并请求，不会每个缩略图都重新验证；等待检测期间取消的预览不会恢复。
- 手动重新检查可重新验证，媒体任务运行时拒绝切换工具；安装说明在插件菜单中可打开。
- 附带上一版未封装的工具栏单行布局，修正了短时低帧率视频最后采样点越界导致的拼图空输出。

## 内置工具

FFmpeg 8.0.3，x264 固定提交 `0480cb05fa188d37ae87e8f4fd8f1aea3711f7ee`。
两套 Mach-O 可执行文件：`darwin-arm64` 与 `darwin-x64`。工具最低 macOS 12.0，
插件仍需满足 Adobe 本身系统要求；目标 Adobe 25.x / CEP 12。Windows 不支持。

构建只有 Apple 系统动态库依赖，无 Homebrew 路径。FFmpeg 官方源码的签名与固定 SHA-256
已验证；所有编译输入记录于 `manifest.json`。GPL-2.0-or-later，未启用 nonfree。
完整对应源码、许可证、配置与构建脚本随包 `extension/vendor/media` 分发，也单独提供源码 ZIP。
通过独立子进程调用，不把 FFmpeg 库链接进 CEP；不宣称解决全部专利或法律适用问题。

## 已执行验证

- 完整单元/媒体/文件系统/宿主模拟测试 192 项通过，0 失败、0 跳过；JavaScript、Perl、Zsh、XML 和版本一致性检查通过。
- ARM64 原生与 x64 Rosetta：H.264/AAC 转码、FFprobe JSON、PNG/JPEG、波形、xstack 拼图和必需能力列表通过。
- `lipo` 架构、`otool` 系统依赖、`codesign` 临时签名验证通过。
- 系统优先、不完整配对回退、损坏哈希阻止执行、版本/能力失败回退、进程组超时清理、原始素材不变、取消与检测状态覆盖。
- 整包在临时用户目录排除系统 FFmpeg 查找后，完成内置安装、升级、运行时检测、元数据、海报、波形、拼图、视频代理、音频代理、截图帧与可恢复卸载。
- ZIP 完整性、ZIP 解压与源目录比对、DMG 内建校验、只读挂载与 ZIP 全内容/权限比对由打包器每次执行。
- 最终附件校验和见 `SHA256SUMS.txt`，最终包验证见 `Package-Verification.json`，隔离安装执行结果另附 `Install-Verification.json`。

## 尚未验证与限制

- Intel 仅经 Rosetta 执行测试，未在物理 Intel Mac 验收；Intel 编译禁用了汇编优化，软件编码速度可能降低。
- 不代表所有 Adobe/macOS 版本均已验证。未在用户日常 Pr/AE 工程内进行新一轮写入，不触碰实际安装目录或素材。
- 测试通过隔离系统候选目录验证无依赖环境，并没有卸载用户现有 FFmpeg；隔离安装跳过实际 PlayerDebugMode 偏好写入。
- 未经 Developer ID 签名和 Apple 公证。工具的临时签名不等于发行签名；首次安装仍可能需要用户在系统设置中放行。
- LUT 一键套用与拖拽标签自动同步仍未开放；右键导入/插入可携带标签，LUT 预览保持可用。
- 旧备份包含完整工具，会占用磁盘；只应在确认无需恢复后通过 Finder 清理指定旧备份。

## 可重复执行

```sh
npm run media:build:macos
npm test
npm run package:macos
node scripts/verify-macos-install.cjs /absolute/path/File-Bridge-0.6.8-macOS.zip /absolute/path/Install-Verification.json
```

新手安装详见包内“先读我-安装说明.txt”，无需执行上述开发命令。
