## 自动化基线

- Node 单元/集成测试：52 项通过，覆盖文件与文件夹安全操作、媒体代理/转码/波形/雪碧图、LUT、状态并发、SMPTE 时间码、CEP 拖拽载荷、Premiere 三种插入位置、实际使用素材清单及项目打包。
- 浏览器交互：280/320/420/720/1200px 与 320px 短高度、列表/卡片、多选、置顶、标签复制粘贴、动态右键子菜单、排序/筛选弹层、长文件名预览关闭按钮、空格预览。
- 真实媒体：播放/暂停、95% seek、I/O、循环、时间码/帧数切换。
