## 已运行的验证

- `npm test`：31 项通过，0 失败。
- 真实 ffmpeg/ffprobe 集成：MOV 代理、音频代理、原尺寸截图和 360p 转码通过；源文件哈希、大小和修改时间保持不变。
- 320 px 与 720 px 浏览器界面验收：搜索浮层、收藏按钮、右键菜单、悬浮信息、LUT 查看器、视频查看器、连续缩放和固定关闭键通过；无未捕获脚本异常。
- 静态安全检查：不存在永久删除素材的代码路径，安全废纸篓保护仍生效。
- 并发状态测试：模拟 Premiere 与 After Effects 同时写入收藏/标签，40 次交错写入无丢失。
