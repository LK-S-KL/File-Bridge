# LK‘s File Bridge 第五版验收表

版本：`0.6.1` · 第五版修复内测

本轮针对第四版后的迭代意见完成了 UI、播放器、文件操作、截图导入和项目打包回归。第四版的 49 项验收继续由 [`V4_ACCEPTANCE.md`](V4_ACCEPTANCE.md) 保留。

| 项目 | 状态 | 验收结果 |
|---|:---:|---|
| 信息卡 / 纯净卡 | 通过 | 工具栏可切换两种卡片；纯净卡隐藏文件名、标签、收藏、格式和角标，信息卡恢复完整信息。 |
| 卡片缩略图 | 通过 | 移除影响 Grid 固有尺寸的布局 containment，并为视频海报增加单帧回退；813px / 620 项压力场景下卡片行高 126.7px、缩略图 16:9、行间无重叠。 |
| 排序 UI | 通过 | 去掉可见“排序依据”，选择框上移并在 280–1200px 视口回归。 |
| 右键子菜单 | 通过 | 插入到、文件转码、添加到文件夹均为悬浮子菜单；菜单滚动条隐藏，短面板内部仍可访问全部操作。 |
| 项目打包 | 通过 | 默认扁平复制最终文件，同名自动编号；只处理 Premiere 时间线清单，不扫描未使用目录。 |
| 插件截图打包 | 通过 | 宿主识别 `LK‘s File Bridge Captures` 中实际使用的截图，显式加入项目清单并复制。 |
| 收藏与元数据文案 | 通过 | 使用“收藏”；移除“悬浮查看”、文件名行和推断置信度文案。 |
| MP4 格式准确性 | 通过 | ffprobe 的共享 BMFF 容器按源扩展名显示 `MPEG-4 / MP4`，MOV 显示 `QuickTime / MOV`；缓存版本升级。 |
| 文件夹操作 | 通过 | 结果数量旁三角菜单提供新建文件夹和上传文件；右键文件夹仅列出插件内可用文件夹，无文件夹时灰置并保留新建入口。 |
| 本地 / 中文路径 | 通过 | 去除用户界面中的 NAS 专属文案；中文文件真实转码和废纸篓回归通过。 |
| 标签 | 通过 | 文案改为“色彩标签”，圆点缩小；新增清除标签，单选/多选均可用并按状态灰置。 |
| 音频预览 | 通过 | 视频单击选中后播放音频；音频卡片悬停播放并在移出时释放。 |
| 缩放与列表 | 通过 | 缩放两端改为动态圆点；列表模式禁用缩放，行内角标和文字缩小且不与色彩标签冲突。 |
| 选中交互 | 通过 | 移除选中操作条；全选移到结果数量右侧并改为勾选状态。 |
| 播放器 | 通过 | 保留音量/相机图标；左右按钮切换上一/下一素材；时间线支持点击定位、Shift 入点、Alt/右键出点和区间高亮。 |
| 截图 | 通过 | 输出 `<源文件名>_Screenshot_YYYYMMDD-HHmm.png`，直接导入 Premiere 项目根目录，不进入插件 Bin。 |

## 回归证据

- Node 单元/集成测试：**60/60 通过**。
- 静态检查：版本字段一致、SMB 扫描通过、无永久删除路径。
- 浏览器回归：320/420/720/1200px；信息卡/纯净卡、列表模式、搜索、结果操作菜单、短高度筛选弹层、右键子菜单、播放器上一/下一素材和鼠标 I/O。
- 交付前会重新运行 `npm run package:internal`，并对 ZIP 做隔离安装、对 DMG 做校验和与挂载验证。
- 几何压力：280/320/420/813/1200px；大目录卡片行高、缩略图比例、列表固定行高和页面横向溢出。
