# LK‘s File Bridge 0.6.7 稳定性复测与内测交付

日期：2026-09-07。修复起点：`190b626`。发布分支：`release/v0.6.7`。

## 结论

原审查报告 25 组问题已逐项处理：21 组完成代码修复，2 组通过移除不可靠的工程写入控制风险，2 组保留底层调用限制。P0/P1 的已知危险路径已修复或禁用；本次可交付定向内测，不代表跨 Adobe 版本和跨硬件矩阵全部验证，也不作“零 Bug”承诺。

## 执行范围

- Node 单元、宿主模拟、文件系统故障注入和 FFmpeg 集成测试：138 项通过，无跳过。
- 版本一致性、JavaScript/XML/Perl/Zsh 检查通过；版本由脚本统一为 0.6.7。
- 安装器测试使用临时安装目录：连续 3 次升级仅保留 1 个有效扩展 ID，卸载后不留同 ID 可加载 manifest；失败恢复旧扩展；其他扩展保持原样。
- 媒体测试使用合成片段和临时缓存，验证黑色片头、主视频流、代理/波形/截图、取消和容量异常；没有改动用户媒体。
- 浏览器通过真实 DOM 执行 10,000 项搜索/滚动/选择，并播放 FFmpeg 生成的 H.264/AAC 测试视频。测试服务对脚本增加仅在测试环境使用的访问点；生产文件没有开放测试接口。
- UI 在 300、320、390、736、1200px 检查主要入口可达与页面无横向溢出；播放器额外覆盖 300、360、736px。
- 没有在用户日常 Premiere/AE 工程中执行写入，没有真实拔断 SMB，没有第二台 Intel Mac 或多个 Adobe 版本的实机矩阵。

## 性能实测

本机隔离 Chrome、736×800、10,000 条合成素材数据：初始 15 张卡片、约 566 个 DOM 节点；筛选与首屏重绘约 5.8ms；最后第 10,000 项可通过滚动访问。原报告 620 项约 7,800 节点属于旧实现，规模不同，不能把两者作为同场景速度倍率。

1,000 项元数据更新：浏览器测试存储适配器只调用 1 次事务，内存更新约 0.3ms。此值不含真实磁盘读写，不能当作落盘耗时。真实状态落盘、损坏恢复和多宿主并发由 Node 临时目录测试覆盖。

UI 工程评分：可访问性 3/4、性能 3/4、响应式 3/4、主题一致性 3/4、反模式控制 3/4，总计 15/20。遗留样式多层覆盖和 Adobe 实机覆盖仍是后续改进点。

## 可重复执行方式

1. `npm test`：所有单元、媒体、文件和宿主模拟测试及版本检查。
2. `LKFB_TEST_NODE_MODULES=<包含 playwright 的 node_modules> node scripts/browser-regression.cjs`：隔离 Chrome UI/真实测试视频回归，输出 JSON 指标和截图目录。
3. `npm run package:internal`：再次执行必要检查，生成新的桌面 ZIP/DMG，内含安装说明和报告；同版本产物已存在时不会覆盖。
